# Security Policy

## Reporting a Vulnerability

We take the security of RepoButler seriously. If you find any vulnerabilities in the database mapping, signature validation, or permission levels, please report them directly to the maintainers rather than opening a public issue.

Email security reports to: **security@repobutler.dev**

Please include:
- A description of the vulnerability.
- Steps or code proof-of-concept to reproduce the issue.
- Impact details.

We will review your submission and respond within 48 hours.
